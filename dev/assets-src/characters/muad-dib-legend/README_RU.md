# Легендарный Муад’Диб — подготовленный DGM v5

Содержит исходный и оптимизированный GLB, визуальный концепт, отчеты, конвертер,
настоящий DGM1 v5 и отдельную JPEG-текстуру. Все восемь исходных анимаций сохранены.

**ВНИМАНИЕ:** этот пакет предназначен для интеграционной ветки. Старый движок
понимает только 18-костный DGM v4, поэтому файл DGM v5 нельзя включать в релиз
до адаптации Babylon-рендера к локальным TRS и бинарным анимационным дорожкам.
KTX2 еще не сделан. См. `dev/docs/MUAD_DIB_DGM_V5_INTEGRATION.md`.
