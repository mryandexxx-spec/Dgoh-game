## Как запускать
В новом чате пользователь пишет **«Пакет N»**. Claude:
1. Готовится по инструкции проекта: репозиторий `mryandexxx-spec/Dgoh-game` (shallow), `cd dev && npm i`, `dev/ARCHITECTURE.md`, раздел «Открыто» в `dev/CHANGES_STATUS.md`. Zip-архив прикладывать не нужно — источник правды репозиторий.
2. Находит пакет в таблице, сверяет статус с журналом `dev/CHANGES_STATUS.md` (выкаченные пакеты помечаются там записью `## vNN — Пакет N: …`).
3. Излагает проект пакета (слои/модули, данные и миграции, бюджеты iPhone и профили графики, связанные пункты «Открыто»), критикует формулировки и предлагает улучшения. UI-пакеты — сначала макет на UI-ките, новые способности — вопрос «участвуете ли в проектировании». Ждёт согласования.
4. Реализует, проверяет, выкатывает по инструкции проекта и `ARCHITECTURE.md` §7–8. После выкатки — отметка статуса в этой таблице.

## Правила работы
Действуют только инструкция проекта и `dev/ARCHITECTURE.md` (главнее этого брифа). Коротко, что изменилось с ред. 3:
- Больше нет `Artifact read`/grep-патчей монолита и `build_pwa.py`. Правка — вручную в `dev/src`, сборка `node tools/build.mjs --deploy`, проверки и выкатка — по `ARCHITECTURE.md` §7, журнал — `dev/CHANGES_STATUS.md`, версия — `dev/version.json`.
- **Вся игра — только альбом** (сделано в пакете 2). Портрет не верстать и не проверять; оверлей «Поверните телефон» уже есть.
- **Макеты:** UI-пакеты (R, E*, A2–A3, B1) начинаются со статического HTML-макета на `dev/docs/ui_kit.html` (отдельный артефакт, фейковые данные, без логики) → согласование → реализация в том же чате.
- **Новая механика** = данные в `data/` + логика в `logic/` (тестируется golden battles/meta) + отображение в `ui/`. Персональные правила героев — данными, а не ветками `if (id === …)` в движке.
- **Профили:** каждый новый 3D-эффект/объект задаёт HIGH / MED / LOW в `render3d/quality.js`; A/B-скриншоты MED `--phone` и LOW.
- **Бюджеты iPhone** (`ARCHITECTURE.md` §4): рост > 10% по draws/проходам/Мпикс/RT на MED или LOW — на согласование с вариантами снижения.
