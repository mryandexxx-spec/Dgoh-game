## Инструмент

`dev/tests/economy/simulate.mjs` — автономный Node-симулятор **исключительно для анализа**. Импортирует чистые таблицы `data/campaign-energy.js`, `data/memory-scrap.js`; проверяет исходники `logic/economy.js`, `logic/gear.js`, `logic/daily.js`, `logic/relics.js`, `logic/account-rules.js`. Никакого доступа к состоянию игры, браузеру или локальным сохранениям. При изменении значимой формулы проверка падает, пока модель явно не актуализируют.

Команды из `dev/`:
```sh
node tests/economy/acceptance.mjs
node tests/economy/simulate.mjs
node tests/economy/simulate.mjs --json
```

Модель включает четыре профиля: новый игрок (1 вход/день), обычный F2P (2 входа), активный F2P (4 входа), endgame (3 входа); 1/2/5 отрядов по пять героев; 7★, снаряжение XIII, ДП3 и ДП7; текущие лимиты энергии и **гипотетические** 6/8 часов запаса, без пополнения и с одним пополнением в сутки; детерминированный PRNG + фиксируемый seed; медиану и p90. Формат JSON даёт подробный приток/расход соляриев, пластали, кристаллов и потери потенциальной регенерации.

## Исходные ориентиры

| Параметр | В текущей игре |
|---|---:|
| Вода: базовый запас / восстановление | 150 / 1 за 20 секунд |
| Свечи: базовый запас / восстановление | 120 / 1 за 30 секунд |
| Максимальное теоретическое суточное восстановление | 4 320 Воды / 2 880 Свечей |
| Один вход при базовом запасе: восполнено / потенциально потеряно за сутки | 150 / 4 170 Воды |
| Обычный бой L/D / Хроники | 6 Воды / 8 Свечей |
| Первичные осколки героя до 7★ из нулевого состояния | 330, включая открытие за 10 |
| Фрагменты всех 6 предметов × XIII уровней на одного героя | 792, без случайных готовых предметов |
| ДП1→7 | 1 450 000 соляриев + отдельные материалы |
| Пополнение Воды (первое за день) | 120 за 50 кристаллов |

Эти числа **не утверждают**, что вся регенерация доступна новичку, что все миссии открыты, либо что 330 осколков реально доступны в одной фарм-миссии.

## Ограничения точности: обязательно учитывать

- Моделируется **условное время целевого фарма**, не реальное прохождение игры. Считаем заранее открытыми все нужные миссии, максимальный успех/3★, один подходящий фрагмент с вероятностью 18% на попытку, все уровни снаряжения доступными за Воду. Это *оптимистическая* модель; некоторые ресурсы доступны за иные валюты/рейды/события, ранние узлы могут быть закрыты.
- Для осколков использована основная выпадательная ветка обычной L/D миссии. ДП-сигналы оценены с существующими шансами 35%/28%/18% и защитой от серии неудач. Пулы предметов, перекрытия фарма и рецептурная специализация упрощены. Дополнительные случайные готовые предметы, сундуки, награды Trials/рейдов/ивентов, мастерские и исходные остатки НЕ включены.
- Стоимость улучшений и ресурсы рассматриваются отдельно от попыток фарма; модель не делает атомарные покупки, не обещает фактическую достижимость баланса и не моделирует рост XP аккаунта. Строки с не достигнутым уровнем аккаунта помечены `accountGateUnmodeled`.
- Суточные поступления daily предполагают, что награды получены и нужные задания/режимы доступны; для новичка это оптимистичный потолок. Режимов/ежедневных задач игра от этой модели не получает.
- При одном/двух/четырёх посещениях энергия тратится до лимита при каждом посещении и восстанавливается между равномерно распределёнными входами. Не учитываются сон, неполная трата, поражения, перегрев PWA или календарные ограничения.
- Гибкие ежедневные задания пока не реализованы. Их альтернативный эффект — только верхняя условная оценка ежедневного сундука 50–300 кристаллов при достижении семи требований. Ничего не начисляется и не меняется.

## Предварительные гипотезы на согласование по итогам модели

1. **P1 F2P-ограничение запаса энергии:** модель обязана показать, насколько 6/8-часовая ёмкость сокращает потери для 1–2 заходов; одновременную инфляцию соляриев/осколков/материалов оценить до изменения лимитов.
2. **P1 стоимость команд и экипировки:** сравнить 5/10/25 героев, проверить узкие места соляриев и пластали, открытия аккаунта и доступности нужных миссий.
3. **P2 daily:** сравнить реальную нагрузку по обязательным ежедневным активностям с идеей альтернативных требований. Новые источники наград без согласованного sink запрещены.
4. **Следующий отдельный пакет:** после разбора базовой модели уточнить по реальным игровым маршрутам уровни/дропы, прогрессию XP и ограничения разблокировки. Только затем предлагать численный ребаланс на отдельное одобрение владельцу.
