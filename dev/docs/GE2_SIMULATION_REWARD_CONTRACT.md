# GE2 — Симуляция наград: согласование UX

Статус: **макет утверждён владельцем 12.11.2026**. Внедрение выполнено в Draft-ветке GE2; опубликованную v91 не менять до зелёного CI и отдельного разрешения на выпуск.
Исходный баг: после `doXSim` вызов `refreshAll()` повторно открывал `openItem(cid,k)` без `partId`. В результате исчезал выбранный рецепт детали. Исправление навигации уже в этой ветке и покрыто браузерным регрессионным тестом на 844×390 и 667×375.

## Рекомендуемый результат симуляции
1. Верх: компактный заголовок «Симуляция ×10», название миссии, расход воды и закрытие.
2. Левая зона: всегда показывать **именно цель фарма**, если переход сделан из рецепта — `frag:itemId:part` и его локализованное имя (Сердечник/Линза и др.), а не родительский `itemId`. Путь «Герой → предмет → компонент».
3. Прогресс: `Получено за запуск +N`; `В запасе X`; `Всего по рецепту Y`; `Осталось добыть max(0,Y - X - доступные старые универсальные)`. Существующие универсальные `S.inv[itemId]` выводить отдельной подписью, не считать дважды при объединённом рецепте.
4. Правая зона: компактная прокручиваемая сетка прочих наград; деньги, материалы, осколки героев, готовые предметы и детали сгруппированы по фактическому ключу выдачи, без повторов. Никакой строки текста наград под кнопками.
5. Нижние кнопки закреплены: «Ещё ×N (цена)» и «Готово». При достижении достаточного количества компонентов первая кнопка должна стать «Вернуться к сборке», не блокируя возможность фарма по желанию.
6. После «Готово» вернуть ровно к выбранной части рецепта. Для поиска осколка героя вернуть на поиск того же героя; для общего симулятора — к исходной миссии.
7. Узкие экраны 667×375: левая колонка 224 px, справа сетка из 4 наград в ряд; основной контент скроллится внутри, панель действий не перекрывает карточки.
8. Пустой дроп искомого фрагмента: заметно «+0 за этот запуск», но без ложного успеха. `Сделано` от количества полученных наград не зависит.
9. Клавиатурная доступность: кнопки с ясными названиями, фокус внутри окна, закрытие Escape, доступный текст статуса; не полагаться только на цвет.

Макет 844×390 и 667×375: `GE2_SIMULATION_REWARD_MOCKUP.html`.
