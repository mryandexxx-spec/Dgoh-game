# Dune GoH — утверждённый пакет v83–v85
Дата: 2026-11-10. Основа: main v82. Владелец утвердил экономику и макеты, можно реализовывать без повторного согласования.
Статус: **в работе**, публикации v83–v85 пока не производились.

## Решения (не менять без нового согласования)
1. Удалить только легендарную Лиет-Кайнс `liet` и «Путь Судьи Перехода», **без компенсации**. Обычная Кайнс `kynes` остаётся. Убрать `liet` из активных отрядов старых сохранений, перенаправить выбранное событие на `muaddib`; ранее полученные награды и достижения не отнимать. Подвиг `devour` с прежним прогрессом продолжает учитывать поглощения Муад’Диба.
2. После уровня аккаунта 50 задание `skill` скрыть и не учитывать: **9 ежедневок, сундук за 7**. При получении 51-го уровня посреди дня не отнимать уже заработанный прогресс сундука и забранную награду.
3. IV–V ярусы `muaddib`: ровно **4 выбранных собственных** героя из шести кандидатов соответствуют требованиям данного яруса (7★, XIII, ДП); два непредставленных героя не проверяются. Пятый — временный сюжетный Муад’Диб 7★, XIII, уровень 85, ДП 5/6 соответственно, без ГЛ «Пророчество»; не добавлять в ростер, не выдавать до конца пяти ярусов. Ярусы I–III без перемен. Сумма наград: 20+40+60+90+120=330 осколков.
4. Подвиги: сортировать «готова награда → в процессе → все ступени получены». В лобби бейдж — **общее число готовых неполученных ступеней**, включая несколько в одной категории; скрывать при нуле. Старый порядок внутри групп сохранять.
5. Автобой: пользователь выбирает постоянную цель тапом/кликом, повторный тап снимает. Провокация нового врага **полностью сбрасывает** закрепление; также смерть, смена стороны, переход волны. Одиночные способности предпочитают цель, массовые и лечебные — по старым правилам. Не менять логику ИИ врага. Пользоваться существующим курсором/HUD без новых эффектов.
6. v85: добавить **только движковую поддержку нескольких волн** по 1–5 врагов с разным составом, тестовые сценарии 2→5→1 и 5→1. Действующие миссии и их награды, сложность, энергия, таблицы `NODES` остаются прежними. `enemy` без `waves` = одна волна. Сохранить HP/щит/TM/cooldowns/fx/смерти/GL между волнами, бесплатного лечения нет. Награда и завершение боя — после последней волны.
