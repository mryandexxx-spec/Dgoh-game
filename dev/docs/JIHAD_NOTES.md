- CQ_DISKS[k] = {r, n, d, f(us, B)}; r: 'c' обычный (характеристики), 'r' редкий (механика отряда), 'l' легендарный (уникальное умение). CQ_RAR — названия/цвета (#c9bea8 / #62c972 / #f39a32), CSS-классы `.r-c/.r-r/.r-l` задают `--rc`.

- Редкие (10): tm, regen, mach, stam, leech (вампиризм 15%), poison (базовая атака 30% яд), avenge (смерть героя → отряду Защита↑+Контратака), spice (+50 пряности на старте), exec (+35% урона по целям <50% ОЗ), counter (30% контратака).
