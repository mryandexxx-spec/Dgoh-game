# BH3 — единый контракт кнопок Муад’Диба и легендарного Барона

**Решение владельца 11.11.2026:** визуальная схема и логика использования кнопок у нового `baron_legend` должны быть **такими же, как у Муад’Диба**, при полностью собственных способностях.

## Реализация
В текущей игре `dev/src/ui/battle/battle-ui.js` уже рендерит по единому списку `['basic','special','ult','gl']` в основном и альтернативном HUD. `gl` — отдельная кнопка с индикатором заряда, одноразовая за бой. `ult` — обычная третья способность, с перезарядкой по ходам. Ни нового UI, ни отдельного `powerful`-слота для Барона **не нужно**.

| Ключ движка | Муад’Диб | Легендарный Барон |
|---|---|---|
| `basic` | Крис-нож Муад’Диба | **Приказ Барона** |
| `special` | Тропа видений | **Власть через страх** |
| `ult` | Наездник червя | **Глаза императора** |
| `gl` | Пророчество Квисац Хадерах | **Падение Атрейдесов** |

Контракт навыков `dev/src/data/baron-legend-abilities.js` сохраняет ключ `powerful` для оригинальной терминологии ТЗ («Глаза императора»), но при адаптации в `dev/src/data/baron-legend-kit.js` способность **отображается в существующем поле `ult`**. Это не подмена умения и не изменение его механики.

Обычные перезарядки Барона: особая — CD 3 и начальный CD 3; третье действие — CD 4 и начальный CD 4. Отдельная GL заряжается стандартным механизмом, выполняется один раз за бой и имеет собственные эффекты, не использует код способностей Муад’Диба.

**Старый HTML-макет** `bh3_baron_powerful_hud_mockup.html` (иллюстрация отдельной новой кнопки) **устарел и не подлежит утверждению**. Авторитетный референс: **существующий игровой HUD Муад’Диба**, который владелец уже согласовал. Новый художественный проект для кнопок не нужен. Ветка пока не включает `baron_legend` в публичный `CHARS`, до интеграции полного события/артов.
