# Релиз «Герои великих домов» — план по пакетам

> Историческая справка: пакеты A–D (v39–v42) выполнялись патчами монолита до рефакторинга. Описания механик актуальны; технические заметки про `Artifact read`, `build_pwa.py` и патчи — устарели. Текущий план — `RELEASE_BRIEF.md`.

Исходная задача — 30 пунктов от Андрея (01.11.2026). Делаем пакетами, каждый — отдельная публикация артефакта и архив PWA.

Технические заметки: Artifact read сохраняет файл с обёрткой — первая строка `<!doctype html><html><head>…` и лишний `</body></html>` в конце; перед патчем срезать обе (публикуется и собирается файл, начинающийся с `<title>`). Статика PWA из приложенного архива; manifest переименовать (name «Дюна: Герои великих домов», short_name «Дюна: Герои»), если архив старше пакета A.
Проверка движка без браузера: строки от `// ===== Dune: Heroes…battle engine` до `module.exports = { SK_KEYS…` → отдельный .js, require в node (createBattle/nextActor/startTurn/act/endTurn/aiPlan). Скриншоты UI: playwright + babylon.js из `npm pack babylonjs@9.30.0` (route на CDN-URL). В headless+swiftshader таймеры «голодают» (setTimeout 450 мс срабатывает через 1–2 с) — долгие тапы в тестах держать ≥2 с.
