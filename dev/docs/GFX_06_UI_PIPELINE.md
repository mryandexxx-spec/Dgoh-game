# GFX-06/PIPELINE — Game UI Production (26.11.2026)

## Решение и границы
Владелец отклонил качество R13/A-Art (торговый пост «Атриум»): функциональный HTML не достиг художественного референса. Вместо R14+ косметических итераций владелец попросил подключить навыки/библиотеки и подготовить последовательность действий. Вариант A и его функциональная компоновка остаются целевыми. Основная игра не изменяется до утверждения нового функционального макета. Не заменять 3D кампании картинками, не менять экономику, сейвы и боевую логику. GFX-04 по-прежнему отложен.

## Инструменты
- .agents/skills/game-ui-art-pipeline/SKILL.md — оригинальная адаптация подхода Layer Game UI (nine-slice, производственный слой ассетов).
- .agents/skills/figma-ui-transfer/SKILL.md — адаптация Figma MCP; при вызовах загружать обязательные установленные skills, а не заменять их этой инструкцией.
- .agents/skills/game-ui-visual-review/SKILL.md — адаптация Impeccable critique/audit и Microsoft frontend-design-review; оригинальные полные плагины не установлены.
- Figma MCP подключён; проверка доступа к конкретному файлу и практическая точность ещё не проведены.
- fal подключён, модель fal-ai/qwen-image-layered подтверждена (1–10 RGBA layers, PNG/WebP). Цена на 26.11: USD 0.05 за единицу images; точная сумма зависит от тарификации результата. Не покупать кредиты. Владелец разрешил попробовать, но сомневается в цене. Один пробный вызов только с подходящим исходным эталоном и проверенной ценой; никаких автоматических платных повторов. При отсутствии доступа/исходника — ручная декомпозиция с Pillow. Пока платный вызов не производился.
- Pillow 12.3.0 — изолированная dev-зависимость dev/tools/ui-art/requirements.txt. Существующий Puppeteer (dev/package.json) для скриншотов и взаимодействия. CSS border-image и Web Animations API — нативные. OpenCV, rembg, Qwen local и Playwright/Pixelmatch не обязательны: добавлять только если выявлена конкретная необходимость. Не менять package-lock, npm runtime, PWA или версии.
- Локальный запуск: python -m pip install -r dev/tools/ui-art/requirements.txt; python dev/tools/ui-art/compare.py reference.png candidate.png diff.png. Дифф — диагностический, не показатель художественной приёмки.
