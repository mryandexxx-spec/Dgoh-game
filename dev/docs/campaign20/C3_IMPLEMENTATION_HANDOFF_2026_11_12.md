# Campaign 2.0 — C3. Интеграция миссий, наград, симуляций и фарма

Дата: 2026-11-12. Ветка `feat/campaign20-c3-mission-integration` (основана на актуальном `main` после слияния C2.2 (PR #36)). Архивный Draft PR #38: https://github.com/mryandexxx-spec/Dgoh-game/pull/38.

## Что реализовано
- В `ui/views/campaign20.js` подробности миссии теперь показывают реальные требования `reqText`, светлую/тёмную сторону, уровни врагов, снаряжение, фактическую мощь выбранного отряда и врага.
- Награды используют `NODE_ITEMS`, `COMPLETE_NODE_ITEMS` и `COMPLETE_RATE` из GE2; осколки берутся из `NODES[].drops`. Для предметов предусмотрен переход через `data-c20item` в существующий `openInfo`. Списки наград и сюжет длиннее одной мобильной страницы переключаются с помощью стрелок, без скролла главного экрана.
- Кнопки боя и симуляций **не дублируют игровую механику**. Они передают index миссии тем же `openSquadSel('camp', i)` и `openSim(i)`, что и старая карта. Исправлено устаревшее условие `if(d.node)`/`if(d.sim)`, из-за которого индекс 0 ошибочно игнорировался.
- В `ui/overlays/info.js` к строкам источников снаряжения или осколков добавлена кнопка «На карте» для тех миссий, где уже есть 3D-пресет. Остальные миссии продолжают работать в старом интерфейсе. `campaign20JumpToMission(i)` выставляет точный режим, главу и выбранный узел и открывает карту.
- CSS C3 ограничивает контент модального окна внутри viewport 844×390 и 667×375 (пагинация вместо скролла).
- `tests/smoke/campaign20.mjs` дополнен проверками требований, реально отображаемого лута, открытия и закрытия info-окна, сохранения 3D-canvas, запуска миссии 0 через squad-select и симуляции 0 через старую экономику.
