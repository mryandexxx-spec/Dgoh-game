1. Release branch включает **ровно один bump 116→117**, запись `dev/CHANGES_STATUS.md`, эту передачу и одноразовый workflow `.github/workflows/release-v117-once.yml`.
2. После CI PR — squash merge в `main` с **точным префиксом сообщения** `release(campaign): publish v117`. Guard одноразового workflow проверяет новый номер, старый root SW, существование C4.14 и конкретное сообщение merge; только после этого вызывает официальный `validate-pwa.yml` через `workflow_dispatch` с явным `publish=true`.

4. Только после **SUCCESS publish job**, отдельного **Pages deployment SUCCESS**, совпадения root SHA и production `app.js` с `v117` и SW с новым VER можно считать v117 опубликованной.
