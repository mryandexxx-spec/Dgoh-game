# UI2 V4 — перенос на остальные меню (12.11.2026)

## Основа

Владелец принял опубликованный художественный стиль UI2 V4: песочно-бронзовая тёплая палитра, материальные поверхности, мягкие тени, новые карточки, без ложных действий. После устранения регрессии ростера **круглые портреты с дугой семи звёзд не трогать**. В этом пакете не менять ростер, 3D карточку героя, окно поиска, профиль, лавки, 3D-арену, Campaign 2.0.

## Пакет UI2-S1: изменяемые экраны

| Экран | Селекторы | Действия, которые сохраняются |
|---|---|---|
| Ежедневные задания | `.chest`, `.quest`, `.chbar`, `.qbar`, `.calcard` | Получение наград, сундук, прогресс, ежедневное обновление |
| Подвиги | `.feat`, `.fpip`, `.fbar` | Пороговые награды, ступени, получение/состояния |
| Испытания | `.trcard`, `.trart`, `.trdetail`, `.trtier` | Выбор режима, доступность по дню, бой/симуляция, действительные 3D-превью |
| Рейд | `.tier`, `.panel` в видах с `.tiers` | Условия ярусов, атака, награда, состояние рейда |

## Реализация

- Файл `dev/src/styles/ui2-secondary.css` импортируется **после** `ui2-v4.css` и базовых игровых стилей.
- Ограниченные селекторы `#view:has(...)` для самостоятельных меню, локальные `.ixpage` для мастерской; не менять разметку, DOM-идентификаторы, обработчики или расчёты.
- Используем линейные/радиальные CSS-градиенты, границы и тени, без тяжёлых backdrop-filter, нового JS или анимаций. Убрать непрерывную декоративную пульсацию на активных ступенях Подвигов.
- Геометрия 844×390 / 667×375: компактные отступы, карточки испытаний в горизонтальном скролле, независимые прокручиваемые колонки мастерской; рейд сохраняет колонку выбора, Джихад — карту.
