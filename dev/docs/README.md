# dev/docs — документы проекта

Перенесены из документов проекта claude.ai (`dune-tools/`) 09.11.2026, чтобы репозиторий был самодостаточным.

**Действующие**
- `PROJECT_INSTRUCTIONS.md` — инструкция проекта: порядок работы, согласование, проверки, выкатка.
- `RELEASE_BRIEF.md` — бриф большого релиза пакетами: таблица пакетов со статусами, ориентиры в коде, описания пакетов (E3, A1–A4, B1–B2 впереди).
- `ui_kit.html` — согласованный UI-кит (палитра, шрифты, портрет, кнопки, панели, вкладки, модалка). Источник стилей для всех макетов.
- `GRAPHICS_ASSETS_ROADMAP.md` — **новая перспективная дорожная карта качества 3D**: цель визуала, подбор Fab/Sketchfab/Mixamo/Quixel/Poly Haven, юридическая проверка лицензий, пилот «Двор Арракина», технические бюджеты iPhone, этапы расширения ростера и арен. Концепция, не активный релизный пакет.

Правила архитектуры — `../ARCHITECTURE.md`; журнал доработок и раздел «Открыто» — `../CHANGES_STATUS.md`; статусы фаз рефакторинга — `../PHASE*_STATUS.md`.

**Исторические (справка)**
- `REFACTOR_PLAN.md` — план рефакторинга монолита (выполнен в фазах 0–7, v45–v68).
- `AUDIT_perf_memory.md` — аудит производительности монолита и статус фазы 1.
- `RELEASE_PLAN.md` — пакеты A–D (v39–v42) эпохи монолита.
- `JIHAD_NOTES.md` — механики Джихада (диски и пр.) на v38.
