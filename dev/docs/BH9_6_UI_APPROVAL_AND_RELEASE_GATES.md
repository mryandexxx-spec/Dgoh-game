# BH9.6 — финальное согласование интерфейса двух сюжетных событий

**11.11.2026 · СТАТУС: художественное согласование UI ожидается.** BH9.4 gameplay/economy согласованы и технически подготовлены, но проектный UI НЕ признан утверждённым. Никаких новых public routes до этого решения.

## Согласованные факты (не переделывать)
- **Марго** — отдельное событие «Шёлковые нити» (3 боя); **Юэ** — «Цена клятвы» (3 боя).
- Вход при уровне аккаунта >= 40, без владения любыми персонажами.
- В каждом бою строго определённая **сюжетная пятёрка**, временная и независимая от личного ростера. Никакого squad selector и требования владеть пятёркой.
- Первая победа: 20 + 30 + 50 осколков; после III — 5 побед в день × 2 осколка, по отдельному лимиту для Марго и Юэ.
- Звёзды повышаются стандартно; total 330 осколков требуется для 7★. Не отдавать 7★ автоматически.
- Переход к легенде Барона только после исполнения его существующих 10 требований, включая Марго/Юэ 7★, XIII, ДП4/ДП3.

## Что показывает каждый экран
1. Вверху: название события, возврат к списку событий, прогресс 0/3…3/3.
2. Слева: обычный информационный блок героя, **без** специального дизайна карточки/неутверждённого портрета. После подключения ассетов — та же стандартная карточка, что и у остальных обычных героев.
3. По центру: три сюжетных этапа с понятным состоянием «пройдено/доступно/закрыто», наградой за первый проход 20/30/50, после III — до 5 повторов.
4. Справа: противники и **фиксированная сюжетная пятёрка выбранного этапа**, отдельная ежедневная квота 0/5, кнопка «В бой» лишь если выполнены gate 40+, последовательность и дневные повторы. Кнопка повторного боя I–II — не показывать (повтор не нужен для фарма).
5. В случае победы/поражения: обычное окно результатов Battle UI, награды только после действительной победы, в одном `persist()`, отказ в повторной выдаче за одно завершение.
6. После достижения 7★: показывать итог события и переход к карточке; никакой бесконечной конвертации фарм-наград.

## Проверяемые устройства
- 844×390 — 3 колонки, одинаковые существующим панелям: имя героя, этапы, бой и награда.
- 667×375 — те же 3 колонки и доступная кнопка; без горизонтального скролла и скрытого текста о лимитах/составе.
- MED/LOW — один EngineHost, иконки эффектов и замена 3D на 2D без изменения прогресса, 0 DOM forced layout в простое.
- Статический HTML: `dev/docs/bh9_4_unlock_events_mockup.html` — обновлён согласно фиксированным отрядам и принятой экономике.
