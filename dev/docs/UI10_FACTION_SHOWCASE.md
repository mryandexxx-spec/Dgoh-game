# UI-10 — фракционные витрины героев

Согласовано владельцем 24.11.2026 после интерактивного HTML-макета. UI-09 уже занят иконками молодого Барона; номер витрин UI-10.

| Ключ | Окружение | Материалы |
|---|---|---|
| frem | Арракис, вход в ситч | песчаник, бронза |
| hark | Гьеди Прайм | графит, чёрная сталь, красные акценты |
| atr | Каладан | мокрый камень, зелень, бронза |

Шесть оригинальных художественных matte painting plates созданы генеративным инструментом OpenAI (gen ID a828cacc-e264-438e-ad22-fb3ef414d7f4). Направление: кинематографическая детализация, монументальная архитектура, открытая передняя площадка, без людей, текста и интерфейса. Атлас 1536×1024, 3×2, порядок frem/hark/atr/cor/bg/mach. Разрезан без ресайза на 512×512; Pillow WebP quality 78, method 6. Никакие кадры фильмов или внешние текстуры не заимствованы. Runtime: dev/assets/img/hero-factions/. Суммарно 151040 B, одна активная текстура 512×512 с mipmaps (~1.33 MiB RGBA8), остальные файлы только в штатном PWA cache.

Профиль определяется по основной известной фракции с явными overrides muaddib=frem, jessica=atr, baron_legend=hark. Не хранится в save. Обычная карточка, закрытая, ДП, легенды используют один каркас. Семантическая индикация снаряжения, улучшений, сторон и ульты сохранена. Изменены материалы/свет только HeroStage, особый свет Дункана сохранён. Один статический billboard и одна текстура для всех gfx-профилей; загрузка по выбранному персонажу и старые текстуры освобождаются, при ошибке возвращается цветной фон и прежний ореол. 2D использует тот же assetUrl. SW и immutable asset map формируются обычной сборкой.
