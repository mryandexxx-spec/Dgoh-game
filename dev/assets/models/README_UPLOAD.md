# Dgoh v82 — установка моделей лагеря

1. Откройте ветку `feature/v82-arrakis-daylight-hub` репозитория `mryandexxx-spec/Dgoh-game`.
2. Откройте папку `dev/assets/models` → Add file → Upload files.
3. Загрузите **три** файла из этого архива: `ornithopter.glb`, `market_tent.glb`, `hologram_table.glb`.
4. Сохраните изменения именно в рабочую ветку, не в `main`.
5. Сообщите в чате, что три файла появились в GitHub. Загрузчик в PR #13 подхватит их автоматически, после чего нужно проверить реальные экраны и пройти CI.

Три текстовых файла `.license.txt` содержат атрибуцию авторов CC BY 4.0. Подробные источники, SHA-256 и требования — `dev/docs/CAMP_V82_ASSET_INTEGRATION.md`.

Сборка до размещения файлов в GitHub отображает старые fallback-модели. **Не публиковать v82 до визуальной приёмки.**
